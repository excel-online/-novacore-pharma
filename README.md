# NovacoreLife Clone

A production-grade full-stack clone of NovacoreLife built with Next.js 14, React, Tailwind CSS, and MongoDB.

## Tech Stack

- **Frontend:** Next.js 14 (App Router), React 18, Tailwind CSS, Lucide React
- **Backend:** Next.js API Routes, Mongoose
- **Database:** MongoDB
- **Styling:** Tailwind CSS + clsx/tailwind-merge

## Features

- **5 Pages:** Home, About, Solutions, Research & Innovation, Contact
- **Sticky Navbar** with backdrop blur and mobile drawer menu
- **Animated Stats** with intersection observer counters
- **Responsive Design** across all breakpoints
- **Contact Form** with validation and MongoDB persistence
- **Newsletter Subscription** with duplicate checking
- **Full API Layer** with standardized JSON responses
